# Personal Portfolio — React + Vite

A single-page, component-based portfolio site built with static props (no state/hooks).
Content lives in `src/data.js`; components just render props.

## Component tree

```
App
├── Navbar
├── Hero
├── About
├── Skills
│   └── SkillCard (mapped)
├── Projects
│   └── ProjectCard (mapped)
├── Contact
└── Footer
```
